Non-negotiable Type 1 rules

Feature-level evidence.
A source-authority line and a proxy line cannot be visually or semantically equivalent.
Stable object graph.
System → subsystem → assembly → component → part → feature → interface.
Provenance-bearing dimensions.
Every technical dimension carries source/class/tolerance/uncertainty and gate state.
Unknowns stay visible.
Unresolved geometry, materials, interfaces and decisions remain addressable rather than being aesthetically filled.
Named SVG layers.
L00 through L99 separate geometry, dimensions, materials, interfaces, sensors, simulation, evidence, unknowns and claim gate.
No drawing self-certification.
Type1 completeness cannot create engineering, manufacturing, approval, deployment or measured-performance authority.
