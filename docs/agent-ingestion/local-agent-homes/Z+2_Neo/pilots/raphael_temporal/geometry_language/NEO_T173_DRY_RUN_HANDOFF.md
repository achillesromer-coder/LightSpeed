## Minimal shared language implemented

Version `cgx.geometry_ternary_language/0.1` is a **typed, small dictionary and safe shorthand compiler**, not a claim of a new trained LLM. It keeps separate:

* `T173:001..173`: geometry role indices, no unverified solidity assumption.
* `T3`: ternary positional navigation address, **not** geometry ID or unique store key.
* `rel:*`: semantic evidence ternary `-1 refuted / 0 unresolved / +1 supported`; each evidential assertion needs source, time, confidence and scope. Conflicting evidence is separate from zero.
* Byte transport: each original byte reversibly maps to **six base-3 digits** `0..2`; no compression or geometry inference.
* `X` intrinsic facet, `E` environment and `R` typed relation form the proposed recursive triad, not an experimentally verified physics law.
* `cgx://...`: possible native Object_ID **only on actual native admission**, not local shortcall authority.

The compiler accepts bounded operator lines and produces `cgx.geometry.ast/0.1` **inert** JSON plans:

```text
SELECT T173:001
RELATE T173:001 adjacent_to T173:002
TRIAD T173:131 interacts_with T173:132
PLAN_HYDRATE T173:131
PLAN_TRANSFORM T173:001 scale=2 unit=m frame=local
ENCODE_BYTES 00ff7f
DECODE_BYTES 000000100110
```

Every AST has `effects_performed: false` and `authority_transfer: false`. The `PLAN_*` forms do not hydrate/transform. The library validates 173 sequential roles, 174 rejection, aliases/overlay classifications, all 256 byte values' binary-ternary roundtrip, unsafe strings, tampering and denied authority. It has no API/network/LLM execution. Natural-language models can *propose* typed ASTs, but the deterministic validator and existing CGX authority pipeline decide whether any operation can later execute.
