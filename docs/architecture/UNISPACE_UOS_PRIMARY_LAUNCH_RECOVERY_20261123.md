## Product line: define one primary product rather than waiting for all research

UniSpace is the *single user-facing, local-first UOS product* over an existing Cognigrex/CGX source, semantic, operational and rights graph. FileSpace, DataSpace, SocialSpace, PrintSpace and IntelligenceSpace are the five canonical facets. ProfileSpace and SystemSpace are scoped views, not two more databases. LOAD/LOAD.Lite, CCC/CYC, Raphael/T173, SAI and Grexes are governed adapters/capabilities, not competing roots. Every output must carry source/revision/rights/evidence and actual execution state. Binary platform integrations coexist with typed ternary/geometric shorthand; no geometric token substitutes for original R0 bytes.

**First genuine user loop (acceptance):** choose an owner-authorised source/file → verify source bytes/version/ACL → reversible R1 parse + explicit loss log → R2 typed relation & trace → R3 classic/spatial UniSpace view → owner-reviewed non-effectful capability → locally evidenced output and reproducible/exportable receipt → restart/rollback. A simulated or source-only step must be displayed as such. The installed runtime path requires its own authenticated native receipt.
