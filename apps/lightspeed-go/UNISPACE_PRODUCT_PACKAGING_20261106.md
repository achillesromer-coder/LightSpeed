Status: **LOCALLY PACKAGED / FOUNDER REVIEW ONLY / NOT PRODUCTION RELEASE**

This is a consumer-facing application shell, intentionally separate from
Cognigrex's unique native identity and from **LOAD.cgx / Alexandria**.
It is not a full offline UOS: authenticated private DataSpace, live FileSpace,
source-index hydration, Grex-native execution, on-chain issuer and device
adapters remain separate components to qualify independently.

## Reproducible packaging
The existing, previously compiled owner-review build is the app-shell source.
The existing verified 12-asset CGX public allowlist is the viewer source.
Use `apps/lightspeed-go/scripts/package_unispace_premint.py` with
`--build`, `--viewer` and `--out` in an isolated owner-controlled path.

The package includes an exact-assets manifest with SHA-256 hashes, a
view-lattice projection, build-tool dependency inventory and a **planned,
not activated**, CCC network sequence. It does not include private review
JSON, secrets, operational datasets, archive originals, native authority,
installation tooling, a writable backend or a device scanner.

2. Founder exports local **design choices only**; no signing or admission.
3. Qualify rights/ACL, bounded host readback, live UX and private routes.

5. Owner separately approves exact signed transaction, fees and network.

   be considered for activation (registry, systems, tools/skills, sources).
7. Manually qualify Grex/Scientific/Engineering and source registries.

   with IP ownership or rights to distribute.
9. Only after science and operations are proven, evaluate fiction engines,
   public-domain/free-use compatible games, Interdimensional Hang and
   inter-file converters as separate licensed consumer domains.
