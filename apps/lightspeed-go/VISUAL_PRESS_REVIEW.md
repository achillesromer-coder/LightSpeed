UniSpace visual Press — private review
====================================

The existing Objects view now owns the composition surface. It reuses the first-spaces family model and the unsigned LOAD batch planner; it creates no database, authority registry, runtime or scheduler.

Add local files or drop them on the full preview. Original bytes receive a SHA-256 source identity. Exact duplicate bytes reuse the current source entry. A source can support multiple presentation layers. Raster images preview from original bytes; SVG/HTML/scripts and unknown .cgx packages remain inert references. No arbitrary file is executed or uploaded. Local intake is bounded to 3 MiB per source, 8 MiB total, 96 source entries and 48 layers. Signed native ingestion, semantic equivalence and source-rights acceptance remain separate operations.

Visual layers: image, object and background. Data layers: information and table. Contract layers: inert contract data. The selected-layer preview, full composition, source stack and inspector share one composition model. Move with pointer drag, arrow keys, exact percentages, stack arrows or row drag. Parent links control grouped visibility; all coordinates are relative to the composition surface. Visual order does not rewrite native dependency order.

Press saves a hash-bound .review.json containing original source bytes, presentation, hierarchy, catalogue fields and any linked unsigned LOAD plan digest. The last-pressed JSON fallback can be copied/saved if downloads are blocked. It is explicitly a frozen snapshot; press again after edits. Restore verifies source bytes, handler derivation, geometry bounds, parent cycles, exact schema, authority flags and composition digest. No source file is overwritten or deleted.

Preparing the existing LOAD batch sends a validated plan to the composer; an existing batch JSON can also be added directly. The composer records only its digest/counts, preserving the original batch as the authoritative review artifact. Requested order is LOAD, then Grex families after accepted LOAD completion. Nothing automatically signs, broadcasts or executes when a chain appears.

Live acceptance: original layout reference restored as a source image, 996-reference / 40-batch plan bound, five layers displayed, information/table/contract edited, stack filtered, keyboard moved and pointer dragged. The complete browser-generated Press JSON was read back and independently restored/rehashed. Twenty-two focused tests passed and the TypeScript/Vite build passed. Browser download completion was not verified; the visible JSON fallback was verified and saved locally.

Publication, native Object_ID admission, contracts, issuer, source rights and DBR are not inferred from this preparation. The existing public-static privacy and runtime convergence holds remain in force. This changes the existing private owner UI at 127.0.0.1:4174 only.
