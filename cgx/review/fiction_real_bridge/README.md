## Identity semantics
ONE proposed stable identity per distinguishable referent; many narrative mentions, domain lenses, aliases, editions and typed source relationships. A reference appearing in a fictional scene is an occurrence, not a duplicate copy of the actual real-world book. A published real book and an imaginary book inside that story with the same surface title remain different referents.

Two independent questions must be answered:
- What is the entity inside its fictional or empirical context?
- What empirical, observational, linguistic or operational reality is independently evidenced?

These can coexist: Klingon was created for Star Trek, yet is a functioning constructed language spoken by actual people. The real-world community practice is a separate source-qualified activity, linked to the single language referent. Nothing implies real Klingon aliens exist.
